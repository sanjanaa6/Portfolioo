## 🌟 Overview

This portfolio serves as an interactive showcase of Sanjana's AI journey, technical expertise, and production-grade software projects:
- **Retrieval-Augmented Generation (RAG)** systems using LlamaIndex, LangChain, and ChromaDB.
- **Deep Learning & Computer Vision** models (YOLOv8, PyTorch, OpenCV).
- **Autonomous Multi-Agent** workflows with LangGraph.
- **FastAPI / Flask** backends integrated with modern React frontends.

---

## ✨ Features

- 🤖 **Interactive Sanjana AI Chatbot**: Built-in virtual assistant that answers visitor questions regarding skills, experience, projects, and contact info in real-time.
- 🎨 **Glassmorphism Cyber Theme**: Dark-mode visual theme with ambient particle neural network canvas animations.
- 📁 **Filterable Project Showcase**: Category filterable cards (LLMs/RAG, Vision, ML, Web) with modal detail views.
- ⚡ **Interactive Skill Meters**: Visual skill breakdowns with animated proficiency metrics.
- ⏳ **Experience Timeline**: Chronological view of milestones, certifications, and academic background.
- 📬 **Contact Section**: Interactive contact form with one-click email copy functionality.

## 🚀 Quick Start

### 1. Clone & Install Dependencies
```bash
git clone https://github.com/sanjanaa6/Portfolioo.git
cd Portfolioo
npm install
```

### 2. Run Locally in Development Mode
```bash
npm run dev
```

### 3. Build Production Bundle
```bash
npm run build
```

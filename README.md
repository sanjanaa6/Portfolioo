# 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/sanjanaa6/Portfolioo.git
```

Move into the project

```bash
cd Portfolioo
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

Build for production

```bash
npm run build
```

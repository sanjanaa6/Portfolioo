## 🌟 Overview

This portfolio is designed as a **premium, AI-inspired digital experience** that showcases my core expertise across Python, Artificial Intelligence, Machine Learning, Deep Learning, Large Language Models (LLMs), and modern full-stack frontend design.

The core philosophy behind this project was to move beyond a static resume and build an immersive, product-like interactive showcase.

---

## ✨ Key Features

- **🎨 Aesthetic UI:** Custom black & orange futuristic visual theme with glassmorphism effects.
- **🌌 3D & AI Visuals:** Interactive background animations powered by **Three.js** and **React Three Fiber**.
- **⚡ Smooth Experience:** Fluid scroll animations and section transitions via **Framer Motion** & **GSAP**.
- **📱 Fully Responsive:** Seamlessly optimized across mobile, tablet, and desktop viewports.
- **💼 Interactive Showcase:** Dynamic project cards with live demo/repo links and interactive skill visualization.
- **📄 Complete Profile:** Dedicated experience timeline, certifications grid, downloadable resume, and functional contact form.
- **⚡ Fast Performance:** Blazing-fast load speeds using Vite and modular React architecture.

---

## 🛠️ Tech Stack

### **Frontend & Frameworks**
- **Core:** React 19, TypeScript
- **Build Tool:** Vite
- **Styling:** Tailwind CSS, PostCSS

### **Animations & 3D Rendering**
- **3D Graphics:** Three.js, React Three Fiber (`@react-three/fiber`), `@react-three/drei`
- **Motion & UI:** Framer Motion, GSAP, Lucide React (Icons)

### **Developer Tools**
- Git, GitHub, VS Code, npm
